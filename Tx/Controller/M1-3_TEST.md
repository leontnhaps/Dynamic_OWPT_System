## M1-3. PV center detection test

1. 기존 서버와 Pi를 실행하고 노트북에서 `Tx/Controller/Com_main.py --server <IP>`를 실행합니다.
2. M1-1에서 1296×972 / 30 FPS / Quality 80으로 Start / Apply를 누릅니다.
3. M1-3 (PV 검출)에서 자동 입력된 `captures/M1-3/pv_detection/runs/y26n_v1/weights/best.pt` 경로를 확인합니다. M4 모델 로딩과 새 SAC 생성도 같은 기본 경로를 사용합니다. 모델 가중치는 저장소에 포함되어 있지 않습니다.
4. 장치 `cuda` (GPU 환경) 또는 `cpu`, 신뢰도 `0.5`, PV class ID `0`을 확인하고 모델 불러오기를 누릅니다. 표시된 클래스 목록과 실제 PV 클래스가 다르면 ID를 바꿉니다.
5. 검출 시작 후 PV 하나를 중앙에 놓습니다. 검출 상자, 중심 십자, 원본 영상 기준 좌표와 confidence를 확인합니다.
6. 기록 시작을 누르고 약 20초 정지 → 좌우/상하 이동 → 화면 밖으로 제거 → 재진입 순서로 시험합니다. 미검출 시 이전 좌표가 남지 않는지 확인합니다.
7. 검출된 상태에서 이미지 저장, 시험 후 기록 종료와 검출 정지를 누릅니다.

저장: `captures/M1-3/` (사용자 지정 `--output` 사용 시 그 아래 M1-3).
- 이미지 저장: 같은 프레임의 원본 JPEG, 검출 표시 JPEG, JSON.
- 기록: 세션별 `session.json`, `detections.csv`. 미검출/오래된 결과는 좌표 공란.
- 검출 FPS는 시작 이후 처리된 프레임의 평균입니다. 수신 FPS와 다릅니다.
- 최신 프레임을 선택하므로 모든 수신 프레임이 검출되는 것은 아닙니다. 처리하지 않은 프레임을 미검출로 세지 않습니다.
- 추론 시간은 모델 호출 및 결과 추출 시간이며 네트워크 전체 지연이 아닙니다. 최초 추론은 준비 작업으로 길어질 수 있습니다.
- 이 탭은 서보 명령을 생성하지 않습니다. 시험 중 다른 탭에서 추적/학습을 시작하지 않습니다.
- 카메라는 고정하고 PV를 움직여 시험합니다. 배선 운용 범위 재시험은 별도입니다.

기존 방식과 동일하게 Ultralytics `YOLO(path)`로 노트북의 가중치를 불러오고 PIL RGB 영상을 `predict`에 전달합니다. 기존 `target_from_boxes`를 재사용하여 최고 confidence PV 하나를 선택합니다. SAC 모델/config는 필요하지 않습니다.

실물 시험 결과는 아직 미확인입니다. 검출 화면과 저장된 CSV를 바탕으로 다음 시험 범위를 정합니다.
