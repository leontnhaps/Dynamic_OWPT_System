## M1-5. Measure Tx Actuator Response and Control Timing

### 1. 준비

- `M1-5` 브랜치에서 기존 서버·Pi·GUI 실행 방법을 사용함.
- Pi 실행에는 `--servo-port /dev/serial0`을 포함함.
- PV 하나를 5 m에 고정함. 레이저는 응답 측정에 필요하지 않음.
- M1-1: 1296×972, 목표 30 FPS, quality 80, 자동 노출·gain.
- M1-2: 실제 연결 확인, 운용 범위 적용, Pan 0° / Tilt 0° 이동. SPD·ACC는 이후 운용할 값으로 설정함.
- M1-5: 기존 공통 PV 모델 불러오기 → 검출 시작.

### 2. 자동 측정

기본값: 이동각 1,3,5° / 반복 10 / 기준 기록 2초 / 이동 관측 3초 / 안정 유지 0.5초 / 최소 문턱 2 px.

자동 측정 시작을 누르면 pan·tilt 각각 양·음 방향 이동과 초기 자세 복귀를 반복함. 기본 설정은 총 240회 명령으로 약 20분 이상 소요됨. 처음에는 반복 1로 동작을 확인한 뒤 10으로 측정함.

명령 범위를 사전에 검사하며, 단일 PV 검출이 부족하거나 응답 판정이 실패하면 중단함. 관측 시간이 부족하면 이동 관측초를 늘려 재시험함. 미검출·다중 PV·오래된 영상·전송 오류를 정상 시험으로 처리하지 않음.

중단 버튼은 다음 명령을 막으며 이미 전송한 움직임을 취소하지 않음. 중단 시 자동 복귀하지 않으므로 M1-2에서 자세를 확인함.

### 3. 기록과 판정

`captures/M1-5/<기존 시각 형식>/`에 저장함.

| 파일 | 내용 |
|---|---|
| session.json | 카메라·모델·SPD·ACC·운용 범위·시험 설정 |
| detections.csv | 프레임 수신·결과 처리 monotonic 시각, PV 좌표, 검출 상태·confidence·처리 시간 |
| commands.jsonl | 명령과 request ID, 명령 전송 직전·응답 수신 시각 |
| summary.json | 시험별 관측 시작·정착 시간, 영상 이동량, 샘플 간격, 축별 중앙값·95백분위·최댓값 |
| frame_*.jpg / frame_*_detection.jpg / frame_*.json | 이미지 저장 버튼으로 동일 프레임의 원본·표시 이미지·메타데이터 저장 |

기준 구간 좌표 흔들림의 3배와 최소 문턱 중 큰 값을 사용함. 연속 두 관측이 기준 위치에서 문턱 이상 벗어나면 움직임 시작으로 추정함. 마지막 구간의 중심 주변에 안정 유지 시간 이상 머물고 남은 기록에서도 유지되면 정착으로 추정함. 측정 간격이 안정 유지 시간의 절반보다 크면 판정하지 않음.

모든 시간 차이는 노트북 monotonic 시계로 계산함. 명령 응답은 Pi 측 명령 처리 결과이며 실제 도달 확인이 아님. 영상 응답에는 명령·영상 통신과 촬영 지연이 포함됨. 순수 서보 응답이나 실제 각속도로 표기하지 않음. 검출은 최신 프레임 방식이므로 관측하지 않은 프레임이 있으며 onset_previous_s와 onset_s 사이가 시작 시점의 관측 구간임.

### 4. 강화학습에 활용

실측 기록을 검토한 뒤 제어 주기와 시뮬레이터 지연을 정함. 정착 시간마다 기다리는 방식으로 자동 고정하지 않음. 통신 지연을 서보 dynamics와 영상 지연 양쪽에 중복 적용하지 않음.

축·이동각·방향별 결과를 확인하고, 실제 운용할 초기 자세와 SPD·ACC에서도 재측정함. 설정 변경 시 별도 세션으로 기록함. 검출 처리율이나 프레임 간격이 불안정하면 이를 먼저 해결함. 제어 주기는 후속 추적에서 실제 명령·관측의 연결을 확인한 후 확정함.
